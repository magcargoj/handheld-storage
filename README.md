# 📱 Handheld Storage Optimizer

**A technical utility for optimizing storage allocation and asset management across handheld gaming devices and embedded systems.**

## 🎯 The Goal
As handheld devices (Steam Deck, ROG Ally, etc.) become increasingly complex, managing high-fidelity game libraries and system assets requires precise calculation. This tool provides a data-driven approach to estimating storage needs based on actual game metadata and device specifications.

## 🛠️ Features
- **Device Library:** Pre-configured storage profiles for modern handheld devices (`devices.json`).
- **Asset Metadata:** Real-world size estimates for thousands of titles (`games.json`).
- **Allocation Logic:** Calculate "Real World" usable space vs. advertised capacity.
- **Product Integration:** Compare SD card and SSD performance tiers for optimal loading speeds.

## 🏗️ Technical Stack
- **Frontend:** Responsive HTML/JS architecture.
- **Data Layer:** Structured JSON datasets for cross-platform portability.
- **Optimization:** Focus on minimalist, zero-dependency performance.
